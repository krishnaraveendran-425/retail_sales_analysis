#Retail Sales Analysis
📌 Project Review

This project analyzes a sample retails dataset containing electronic devices such as laptops, TVs, smartphones, tablets, air conditioners.
The goal of this project is to analyze sales data, identity patterns and generate useful business insights using Excel, SQL and Tableau.
*Note* :- This is a synthetic dataset created for portfolio and learning pur        poses. It does not represent actual company sales data.

🛠️ Tools Used
 1. *Excel* - For Data cleaning and initial analysis
 2. *SQL* - Data analysis and business queries
 3. *Tableau* - Data visualization and dashboard
 4. *GitHub* - Project documentation and portfolio

# Dataset

The dataset contains *41 sample orders* with the following columns:
 1. Order No.
 2. Order Date
 3. Product Category
 4. Product Name
 5. Product Brand
 6. Product Model
 7. Price

 # Excel Analysis

 The following analysis was performed using Excel:
 1. Checked for missing values
 2. Checked for duplicate order numbers
 3. Verified price values
 4. Verified order dates
 5. Calculated total sales
 6. Calculated total orders
 7. Calculated average price
 8. Identified highest and lowest prices
 9. Analyzed sales by product brand
 10. Analyzed sales by product category

# Key findings
1.*Apple* generated the highest sales value among the brands in the sample dataset with total sales **₹891,378**.
